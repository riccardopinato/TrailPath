# TrailPath v1.0.0 — Play Store Draft

## App name
TrailPath

## Short description
Plan outdoor routes, record tracks and navigate with offline maps.

## Full description
TrailPath is an outdoor route utility built for planning, recording and navigation.

Plan routes on an outdoor map, choose an activity profile, inspect distance and elevation, save routes, record your activity and navigate with live progress. Prepare route maps for offline use before leaving coverage and keep essential navigation data available after app restart.

Key features:
- outdoor route planning;
- walking, hiking, running and cycling profiles;
- elevation and ascent/descent;
- GPX import, export and sharing;
- track recording with pause/resume and recovery;
- saved-route navigation;
- offline map preparation;
- Back to Car;
- battery-aware GPS modes;
- local-first activity and route storage.

TrailPath is designed as a practical outdoor tool rather than a social network.
