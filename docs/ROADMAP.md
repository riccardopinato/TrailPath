# TrailPath roadmap

## v0.1 - Strong Foundation
Completed. Architecture, database, service boundaries, localization, themes, CI and application shell.

## v0.2 - Map & Position
Completed. Real MapLibre map, OpenFreeMap basemap, Geolocator engine, live GPS, accuracy state, heading-aware user puck, follow-user controls, runtime permissions and native permission bootstrap.

## v0.3 - Route Planner
Waypoint editing, route requests, snap-to-network, undo/redo, distance, duration and persistence.

## v0.4 - Elevation
Interactive elevation profile, ascent, descent and grade.

## v0.5 - GPX Engine
Robust GPX import/export and system share flows.

## v0.6 - Track Recorder
Background GPS recording, pause/resume, autosave and crash recovery.

## v0.7 - Navigation
Route following, voice/haptics, off-route detection and back-to-route.

## v0.8 - Offline
MapLibre offline regions, storage controls and fully offline use of prepared routes.

## v0.9 - Outdoor Intelligence
Activity profiles, battery modes, back-to-car and safety/share tools.

## v1.0 - Release
Onboarding, Premium foundation, optional backup/sync, accessibility, performance and store QA.
