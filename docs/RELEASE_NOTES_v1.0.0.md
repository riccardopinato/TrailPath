# TrailPath v1.0.0 — Release Notes

Build: 28

## Highlights

- Route planning with shared Android/Web core.
- Real OSM routing with explicit failure handling.
- Elevation, GPX import/export and route editing.
- Recording with pause/resume, autosave and crash recovery.
- Saved-route navigation with off-route handling and arrival detection.
- Offline map preparation, restart persistence and no-network navigation validation.
- Back to Car, battery-aware GPS modes and safety checks.
- First-run onboarding, privacy hardening and accessibility improvements.
- Release-mode CI, AppLab E2E, size budget and dependency audit.

## Release state

The codebase is feature-frozen for v1.0.0. Production publication remains blocked until:
1. a store-signed AAB is built and verified;
2. physical-device QA is completed on the exact release candidate;
3. Play Store metadata/screenshots are reviewed and accepted.

No public v1.0.0 tag or GitHub Release should be created before the certification verdict is CERTIFIED.
